Arisen's Toolbox FAQ

Saves, safety, mods, updates, cheat table questions and troubleshooting for the Dragon's Dogma 2 companion.

Is Arisen's Toolbox safe to use?

It edits the loaded save in a single-player game. The app backs up the save before the first change of a session, keeps ten recent backups plus a pinned first backup, and records undo for most edits. Back up your own save as well; any save editor carries risk.

Is Arisen's Toolbox a trainer?

It is a companion and save editor, not a memory scanner. It talks to a REFramework Lua script and changes game state through the game's own classes. That covers trainer-like edits: items, stats, skills, pawns, movement, fast travel and summons.

Does it work offline?

The app connects to the game on your PC through local files in the REFramework data folder. It does not need an online account. The item list is cached after one successful load, so the Item Giver can still show items offline.

Will a Dragon's Dogma 2 update break it?

The file-based bridge is designed to survive game title updates, but REFramework itself and class fields can change. If something stops resolving, update REFramework and the bundled bridge from the Connection screen, then check the release notes.

Does it work with mods?

It works alongside REFramework mods. Load-order and script conflicts are possible with mods that patch the same game classes, so test on a backed-up save.

Can I edit pawns, ratings and badges?

Yes. Rating & Badges edits the selected pawn's thumbs-up, hearts and badge progress. Names renames the Arisen, the main pawn and hired pawns. Select Main pawn in the top bar before opening either screen.

Can I change jump height, movement speed and fast travel?

Yes. The Mods screen has jump height, air time, no fall damage, movement and ladder speed, fast travel to a map pin or quest marker, enemy respawn timers, boss summons and nearby-enemy tools. Sliders apply when you release them.

Can I use it on Steam Deck or Linux?

The released app targets Windows 10 and 11. It is not a native Linux or Steam Deck build. Running the Python source under Proton is not a supported path.

Does it edit the save file directly?

No. The app talks to the running game through REFramework; the game writes the save. The app also copies the save folder to its backup directory before the first change.

Where are backups stored?

Under %LOCALAPPDATA%\ArisensToolbox\backups. The app keeps a pinned first backup and the ten most recent ones. Restore is on the Connection screen.

Is the source code open source?

The source is public on GitHub, but the license is all-rights-reserved, not an open-source license. You can read it and report issues; redistribution needs permission.

Why does Windows warn about the exe?

The exe is unsigned and packaged with PyInstaller, so SmartScreen can warn. Download only from the GitHub release or the Nexus page, then use More info, Run anyway.

Can I use the cheat table without the app?

Yes. The CT has its own bridge installer on the Connect tab. You still need Cheat Engine 7.x and a loaded save. The app offers save backups and undo that the CT does not.
