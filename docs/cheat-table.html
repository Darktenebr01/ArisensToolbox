Arisen's Toolbox releases include a Cheat Engine table with the same game-side bridge, for players who prefer CE over the desktop app.

How to open it

  1. Install Cheat Engine 7.x.
  2. Attach CE to DD2.exe and load a save.
  3. Open the .CT from the release folder.
  4. Tick the panel entry, press Connect + load enums, then use the tabs.

The CT can install or update the bridge from the Connect tab. If the game runs an older bridge, the new commands return "unknown command" until you install and restart.

The CT is a separate front-end, not a replacement for the app's save backup and undo. Back up the save before edits. Single-player only.

App or table?

Use the app for backups, undo, the item library cache and the full item editor. Use the table if you already work in Cheat Engine and want the same edits in a compact panel. Both embed the same bridge, so they do not downgrade each other when versions match.
