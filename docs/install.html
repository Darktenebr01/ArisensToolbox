How to install Arisen's Toolbox for Dragon's Dogma 2

The release is a Windows app. Install REFramework and the bridge from the Connection screen, then connect to a loaded save.

Before you start

  • Windows 10 or 11, 64-bit
  • Dragon's Dogma 2 on Steam
  • The game installed in a folder you can write to
  • A save you can back up

Install from the release zip

  1. Download the latest release from GitHub Releases or Nexus Mods.
  2. Extract the zip to a normal folder, for example C:\ArisenToolbox. Do not run the exe from inside the zip.
  3. Run ArisensToolbox.exe. If Windows SmartScreen appears, choose More info and Run anyway only if you downloaded it from the official release.
  4. On the Connection screen press Start. The app installs REFramework when missing, installs or updates the bridge, and launches the game through Steam.
  5. Load your save, then press Connect. The first change in the session creates a backup.

If the app cannot create a temporary directory

That message comes from the one-file packer, before the app starts. Move the exe to a writable folder such as C:\ArisenToolbox and run it again. If it persists, use the onedir build when the release provides one, or run the source with python main.py. Do not disable antivirus protection globally.

Troubleshooting

The game folder is not detected

Start Dragon's Dogma 2 once through Steam, then press Start again. If Steam is installed in a non-standard library, point the app at DD2.exe when prompted.

Connected but commands say "unknown command"

The game is running an older ddbridge.lua. Press Install / update bridge + REFramework, restart the game, and reconnect.

Nothing happens after pressing Start

Check the log on the Connection screen. Steam must be running, the game must not be in a loading screen, and REFramework must have loaded. A first launch can take longer while REFramework downloads.

Running from source

python -m pip install -r requirements.txt
python main.py

Building an exe needs PyInstaller: build.bat, then dist\ArisensToolbox.exe.
